# 画风图谱 · 经典艺术与插画流派视觉解构 (Art Style Archive)

基于统一基准测试场景，解构 14 种经典绘画与插画流派的**笔触肌理、色彩语言、光影逻辑与 Prompt 结构化对照**。支持 9 大基准场景 × 126 组全量视觉图谱浏览与双画风同屏无级滑动对比。

## 核心功能

1. **126 组基准视觉图谱**：覆盖人物肖像、海滨电车、镜湖古树、午夜古书店、云海蒸汽飞艇、深海发光水母、赛博雨夜拉面馆、森林魔导树屋与荒漠机械驼兽 9 大经典基准场景。
2. **14 大经典流派解构**：涵盖厚涂油画、通透水彩、印象派、丝网波普、浮世绘木刻、美漫网点、80s City Pop、新艺术运动、装饰风艺术、赛博朋克、吉卜力赛璐珞、极简矢量、16-bit 像素风与绘本蜡笔拼贴。
3. **双画风同屏对比台**：支持并排视图与实时无级滑动拆分，直观对照不同流派的笔触微结构与色彩构成。
4. **结构化 Prompt 解构与导出**：提供核心修饰词提取、一键复制及场景全量 Prompt 库导出。
