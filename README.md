# 画风图谱 · 经典艺术与插画流派视觉解构 (Art Style Archive)

基于统一基准测试场景，解构 34 种经典绘画与插画流派的**笔触肌理、色彩语言、光影逻辑与 Prompt 结构化对照**。支持 9 大基准场景 × 34 种艺术风格共 306 组全量视觉图谱浏览、中英文双语切换、极速轻量缩略图加载与全屏沉浸式灯箱。

## 核心特性

1. **306 组基准视觉图谱**：覆盖人物肖像、海滨电车、镜湖古树、午夜古书店、云海蒸汽飞艇、深海发光水母、赛博雨夜拉面馆、森林魔导树屋与荒漠机械驼兽 9 大基准测试场景。
2. **34 大经典与现代流派解构**：
   - **传统画种**：厚涂油画、通透水彩、印象派、野兽派、炭笔素描、洛可可粉彩、点彩派、克里姆特金箔、暗黑奇幻水墨等；
   - **版画与媒介**：浮世绘木刻、丝网版画/波普艺术、哥特木刻蚀刻、孔版印刷(Risograph)、粉笔黑板报手绘等；
   - **时代美学**：美式复古网点漫画、80s City Pop、新艺术运动、装饰风艺术(Art Deco)、包豪斯构成、欧普视错觉等；
   - **现代数码**：赛博朋克霓虹、吉卜力手绘风、极简扁平矢量、16-bit 像素艺术、低多边形三维(Low Poly)、定格黏土动画等。
3. **中英双语国际化 (i18n)**：支持一键切换中文/英文界面，自动持久化偏好设置。
4. **极致性能与视觉体验**：600px 紧凑缩略图与双层平滑交叉淡入灯箱，杜绝大图加载跳变与闪烁。
5. **结构化 Prompt 解构**：保留完整作图 Prompt，支持 Hover 一键复制与中英文元数据即时检索。
